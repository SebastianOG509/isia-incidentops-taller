# Roadmap de Producto — IncidentOps

| Hito | Nombre | Resultado de negocio esperado |
| :--- | :--- | :--- |
| **H001** | Triaje multi-interfaz | Clasificar y enrutar reportes de forma determinista, sin guardarlos, para consumo inmediato desde web y terminal. |
| **H002** | Resumen de incidentes activos | Consultar desde web y terminal los incidentes activos, cuántos incumplen su SLA y filtrar por componente. |
| **H003** | Ciclo de vida, duplicados y SLA | Registrar incidentes de forma persistente, alertar si ya existe otro equivalente abierto y auditar su SLA en cualquier instante. |
| **H004** | Persistencia relacional dedicada y runtime en contenedores | Ejecutar el servicio de forma reproducible en contenedores con una base de datos relacional dedicada y un chequeo real de conectividad. |
